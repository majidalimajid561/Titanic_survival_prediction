# Titanic_survival_prediction

## What is this project?
A machine learning model that predicts whether a passenger survived the Titanic disaster,
using passenger features like age, sex, class, and fare.

## Dataset
The dataset is the classic [Titanic dataset](https://www.kaggle.com/c/titanic/data) from Kaggle
(also available in Seaborn).

## Approach
- Explored data, handled missing values.
- Used a scikit‑learn Pipeline with imputation, one‑hot encoding, scaling, and Logistic Regression.
- Evaluated with accuracy, confusion matrix, and classification report.
